# Geopolitical Shock & Sector Resilience Analysis

 Overview

This project explores how geopolitical conflicts affect different sectors of the stock market and whether historical market behavior can be used to evaluate sector resilience during future geopolitical shocks.

The project uses Python for automated market-data collection and SQLite/SQL for the core data storage, analysis, and scenario-based ranking.

Objective

The goal is to analyze historical geopolitical events, measure sector-level abnormal returns and risk, and use these patterns to evaluate a hypothetical future geopolitical scenario.

Tech Stack

- SQL / SQLite
- Python for data collection
- Window Functions
- CTEs
- Financial Market Data
